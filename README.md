# RollerCoasters

電腦圖學課程的 Windows 桌面過山車編輯器，使用 C++、FLTK 1.3.11 與 OpenGL。

## 建置與啟動

安裝 Visual Studio 2022 或更新版本（例如 2026）的 **使用 C++ 的桌面開發**（MSVC、Windows SDK、C++ CMake tools），以及 PowerShell 7.4 以上版本。

最簡單的方式：clone 後在 Visual Studio 選「開啟資料夾」（或在檔案總管對資料夾按右鍵「使用 Visual Studio 開啟」），
Visual Studio 會讀取 `CMakePresets.json`，選 `Visual Studio (any version) / x64` 與 `Debug`，啟動項目選 `RollerCoasters.exe` 後按 F5。
VS Code 搭配 CMake Tools 擴充也一樣選這個 preset。
世界（約 1000 萬格方塊）在啟動時於背景生成，期間顯示載入畫面與進度條；Release 約一兩秒（依電腦而定），Debug 沒有最佳化又有執行期檢查，會慢上數倍到十幾倍，只想看效果或展示時改選 `Release`。
第一次生成後，島與海床會像方塊遊戲的存檔一樣存到 exe 旁的 `data\saves\`（`island.world`、`flat.world`、`ocean.world`，各約 2 MB），之後啟動顯示 `Loading world` 直接讀檔，不再重新生成。重新建置任何會影響世界的原始檔（`LandWorld`、`OceanWorld`、`WorldShape`、`WaterFlow`、`PixelArt`）後存檔自動失效並重新生成；想強制重新生成就刪掉 `data\saves\`。這個 preset 不綁定 Visual Studio 版本，由 IDE 自行載入已安裝的 x64 編譯器。

命令列建置與完整檢查，以下命令均在此 repository 根目錄執行：

```powershell
pwsh -File scripts/setup-tools.ps1
pwsh -File scripts/check.ps1 -Stage build -Config Debug
./out/build/windows/Debug/RollerCoasters.exe
```

目前支援 Windows x64 的 MSVC 與 clang-cl。隨附的 `.lib` 不支援直接切換 Linux、MinGW 或 ARM。
工具版本與官方下載的 SHA256 固定於 `tools.json`；檢查腳本使用原生 CMake／clang-format。

### 使用 Clang

同樣需要 Visual Studio C++ 工具與 Windows SDK；檢查腳本會自動載入 x64 開發環境。

```powershell
pwsh -File scripts/setup-tools.ps1 -WithClang
pwsh -File scripts/check.ps1 -Stage all -Compiler clang -Config Debug
pwsh -File scripts/check.ps1 -Stage all -Compiler clang -Config Release
./out/build/clang/Release/RollerCoasters.exe
```

只編譯可將 `-Stage all` 改為 `-Stage build`。MSVC 與 Clang 使用獨立的建置目錄。

## 操作

程式一開啟就是展示模式：自動載入 `Grand Tour` 路線並切到 `Train` 相機，列車停在上岸處，按 `Run` 開始行駛（`Run` 預設不開）。
想自己編輯軌道時按 `Reset`（回到平坦草地島、顯示控制點、World 相機），想回到展示按 `Grand Tour`。

- `Grand Tour` 是一條 62 個控制點的長路線（每個轉彎的夾角都不小於 90 度，沒有銳角的急彎或髮夾彎），繞行整座方塊風島嶼與東北新大陸後潛入海底再回來：
  從海上飛向村莊（風車、小屋、麥田、路燈）→ 沿雪山岩壁螺旋爬升，跨過從山上一路跌進海裡的溪流瀑布 →
  從山頂俯衝，掠過漂浮島與它的長瀑布 → 鑽進彩色黏土地層的峽谷，貼著海水從瀑布旁穿過 →
  越過熔岩河，爬上火山並從火山口的熔岩湖上方飛過 → 高架橋跨過自己的軌道 → 穿過有礦石、燈籠與水晶的岩山 →
  經過巨大蘑菇與櫻花林回到草原，接著出海入水走完海底段。
- 相機：`World`（自由環繞）、`Train`（第一人稱，視角略微朝下，爬坡時仍看得到地面）、
  `Chase`（沿軌道跟在最後一節車廂後上方，看得到整列火車與揮手的乘客；彎道和隧道裡也不會穿進岩壁）、`Top`（正上方，主島與東北陸地都完整放進畫面，不畫雲）、`Fly`（觀察者模式，見下）。
- World：觸控板雙指移動旋轉（滑鼠滾輪左右傾斜也可）；在空白處單指（左鍵）拖曳、Shift + 左鍵拖曳或右鍵拖曳也可旋轉。
- 平移：Alt 或 Shift + 雙指捲動；Alt + 在空白處左鍵拖曳或 Alt + 右鍵拖曳。
- 縮放：滑鼠滾輪向上放大、向下縮小；觸控板雙指張開放大、捏合縮小。觸控板可以一邊移動雙指旋轉、一邊捏合縮放；拖曳旋轉或平移時也能用滾輪縮放。
- 重設：Shift + 左鍵雙擊或右鍵雙擊。
- Train（坐在列車上）：可以轉頭看四周，視線跟著列車前進與轉彎。
  - 轉頭：在畫面上用左鍵或右鍵拖曳（往右拖看右邊、往上拖看上面），觸控板單指按住拖曳或雙指移動也可以（雙指時畫面跟著手指走，和 World、Fly 一樣，放開就停）。左右可以轉一整圈往後看，上下最多 85 度。
  - 回到正前方：雙擊畫面，或按 R／Home（R 依實體按鍵位置讀取，開著注音也有效）。每次切換到 Train 都從正前方開始。
- Fly（觀察者模式，操作仿照方塊遊戲的觀察者模式）：每次切換到 Fly，都從當下的畫面接續，畫面不跳動；World、Train、Chase 都一樣（Train 的傾斜會擺正，因為 Fly 保持水平線），從 Top 切換則在 Top 畫面中央上方往下看。
  - 滑鼠看：在畫面空白處點一下，滑鼠游標隱藏，移動滑鼠（或在觸控板上滑一根手指）直接轉視角；按 Esc 放開滑鼠。點到控制點仍是選取與拖曳；滑鼠鎖定且 `Edit` 開啟時，滑鼠鍵照 Minecraft 的方式建造（見下方「在 Fly 相機下建造」）。
  - 移動：按住 W／A／S／D 水平前後左右（低頭時也不會鑽進地面）、空白鍵上升、Shift 下降（E／Q、Page Up／Page Down 也可以）；按住 Ctrl 加速 2.5 倍。
  - 輸入法：Fly 模式會暫時關閉這個視窗的輸入法（例如注音），離開 Fly 自動恢復；W／A／S／D、空白鍵、Shift、Ctrl、E／Q、F、`Home`，以及編輯用的 G、R 依實體按鍵位置讀取，所以中文輸入法或其他鍵盤配置下也能飛。
  - 速度：滑鼠滾輪往上變快、往下變慢；也可用 +／- 鍵或 `Camera` 面板的 `Fly` 滑桿（每秒移動單位）。
  - 視野：`Camera` 面板的 `FOV` 滑桿調整垂直視野（30–120 度，預設 70 度），同時套用到 World、Train、Chase 與 Fly；Top 是正交投影，不受影響。
  - 其他看法：右鍵拖曳、方向鍵、觸控板雙指移動（放開手指就停，不會慣性旋轉）。
  - 觸控板：雙指張開／捏合（或 Ctrl + 捲動）沿視線前進後退，可以一邊轉頭一邊前進；Alt + 雙指移動左右、上下平移。
  - 找方向：畫面中央有準星；地面延伸到地平線。按 F 平滑轉向列車，按 `Home` 回到 World 視角位置（`R` 留給傾斜控制點）。
  - 範圍：相機最低可以飛到 y = −200（可以鑽到地面以下看潛入地底或海底的軌道，從下方也看得到地面），最高 600，且不會離場景中心超過 1000 單位。
- 控制面板在視窗右側，外觀仿 3D 建模軟體的屬性編輯器：深灰面板、圓角灰色按鈕，開啟或選取的項目是藍色。由上到下六個面板：
  `Ride`（Run、前後步進、ArcLength、Speed）、`Camera`（World／Train／Chase／Top／Fly、Fly 速度與 FOV）、
  `Track`（Spline Type、Edit、Add／Delete Point、Load／Save／Reset、R±X／R±Z）、`Transform`（選取控制點的 X／Y／Z，可直接輸入）、
  `Lighting`（Light+、Shadows、Headlight、Bloom、SSAO、Time）、`World`（Water、Rain、Scenery、Grand Tour、Textures）。Load／Save 讀寫軌道文字檔，開的是 Windows 檔案總管的「開啟」／「另存新檔」視窗（存檔時會自動補上 `.txt`，覆蓋舊檔前會先詢問），預設位置是 exe 旁邊的 `TrackFiles\`（build 與安裝時建立，程式啟動時會切到 exe 所在資料夾，不論從 Visual Studio、雙擊或終端機啟動都一樣）。
- 編輯控制點（先開啟 `Edit`，快捷鍵 `F4`，像方塊遊戲切換遊戲模式；World、Top 與 Fly 相機）：`Edit` 關閉時控制點不顯示也不能選取。左鍵點選，選到的控制點變橘色並出現移動把手；中鍵也能選取（只選不拖），沒有中鍵的觸控板按 `C` 選游標下的點（Fly 鎖定滑鼠時選準心對到的點）。
  - 拖紅／綠／藍箭頭沿 X／Y／Z 軸移動，拖小方塊在該平面內移動，直接拖控制點則平行於畫面移動。
  - 鍵盤操作與 3D 建模軟體相同：`G` 移動、`R` 傾斜（改變控制點的上方向），之後按 `X`／`Y`／`Z` 鎖定軸，`Shift` + `X`／`Y`／`Z` 鎖定另外兩軸的平面；
    左鍵或 Enter 確定，右鍵或 Esc 取消並還原。按住 `Ctrl` 以 1 單位（傾斜時 5 度）吸附。
  - 新增控制點：按 `Add Pt`（或 `Shift` + `D`），把滑鼠移到軌道上會出現黃色預覽點，左鍵點下就插在那裡，新點自動選取，按住不放可直接拖曳；
    `Esc` 或右鍵取消，點到軌道以外的地方仍可照常旋轉相機。新點插在點擊處前後兩個控制點之間，軌道仍經過點擊處，所以形狀幾乎不變；
    傾斜方向取前後兩點的內插，列車留在原本的位置。`Edit` 關閉或正在坐車時按 `Add Pt` 會自動開啟 `Edit` 並切到 World 相機。
  - 在 Fly 相機下建造（滑鼠鎖定、`Edit` 開啟；`Add Pt` 或 `Alt` + `D` 會直接鎖定滑鼠），操作照 Minecraft：
    - 準心對到的控制點外圍出現白框；左鍵敲掉（刪除）它，中鍵或 `C` 選取它，右鍵在準心處放一個新點。
    - 搬動：按 `G` 拿起準心對到的點（沒對到就是已選取的點）並直接拉到準心上、保持原本的距離，畫面不會停，照常轉視角、飛行，點固定在畫面同一處跟著走，滾輪調遠近；再按 `G` 或左鍵放下（一步 `Ctrl` + `Z`），`Esc` 放回原位。（World／Top 的 `G` 仍是跟著游標移動。）
    - 準心前方的黃點是右鍵會放的位置，黃線連到它會接上的軌道段；滾輪調遠近（往上推遠、往下拉近），左上角顯示距離。建造時滾輪不改飛行速度，速度用 `+`／`-` 或 Fly 滑桿。
    - 新點放在黃點那個位置，插在離它最近那段軌道的前後兩點之間；刪點時列車留在原處附近。每次放、敲都是一步，`Ctrl` + `Z` 可復原。`Edit` 關閉時滑鼠鍵不做事、滾輪照常調速度。
  - `Delete` 或 `X` 刪除。
  - 上一步／下一步：`Ctrl` + `Z` 或 `Track` 面板的 `Undo` 回到上一步，`Ctrl` + `Y`、`Ctrl` + `Shift` + `Z` 或 `Redo` 到下一步，可以連續往回、往前（最多 200 步）。
    新增、刪除、移動、傾斜控制點，`Transform` 欄位、R±X／R±Z，以及 `Load`、`Reset`、`Grand Tour` 都算一步；新增後直接拖曳算同一步。
    復原時選取也一起回到當時的點；列車留在原處，只有點數改變時（新增、刪除、載入）才回到當時的位置。做了新的修改後就不能再到下一步。
  - 在 Fly 相機下編輯：飛行鍵（W／A／S／D、空白鍵、Shift、Ctrl、E／Q）一律用來飛行，不會觸發編輯。`G`、`R`、`Ctrl` + `Z`／`Ctrl` + `Y` 照常；
    新增改用 `Alt` + `D`（`Shift` + `D` 是下降加右移，`Ctrl` + `D` 是加速右移），刪除只用 `Delete`（`X` 在 Fly 下不刪點，避免飛行時誤按）。
    按 `G`／`R` 開始編輯時相機會停住、滑鼠鎖定解除，讓控制點跟著滑鼠走，`Shift` + `X`／`Y`／`Z` 也能鎖定平面；結束後仍按著的飛行鍵會繼續飛。
  - 數字鍵盤 `1`／`7`／`0` 切換 World／Top／Train 相機。畫面左上角會顯示目前相機、選取的控制點與操作中的數值。
  - 控制點是編輯輔助，不投射陰影。
- 光影：`Light+` 開啟 shader 逐像素光照與 shadow map 陰影，關閉即回到原本固定管線畫面。
  `Shadows`、`Headlight`（火車頭燈）、`Water`（島外海面波浪、反射與折射）、`Bloom`（泛光與 god rays）、`SSAO` 可個別開關；
  `Time` 滑桿 0–24 時移動太陽與月亮：日出、日落時陽光轉成金橘色，地平線朝太陽一側是橘金、另一側是粉紫，雲底被染色，海面有金色倒影；夜晚有方形月亮與星空，場景由偏藍的月光照亮，最容易看到頭燈、窗戶與燈籠。顯卡不支援時自動退回原本畫法。
- 列車：方塊風蒸汽火車頭拉著五節木頭礦車，每節各自沿軌道轉向；每節坐一位揮手的方塊人乘客，火車頭有頭燈，最後一節有尾燈。
- 場景（`Scenery` 開啟）：約 500 單位寬的方塊島嶼，內建貼圖全在程式裡畫出，不附帶外部材質包。
  - 地形：尖峭雪山與雲杉林、惡地峽谷、火山與熔岩河、有礦石與燈籠隧道的岩山、草原與櫻花湖、西方外海小島、東北方隔著海峽的紅樹林沼澤與竹林丘陵。
  - 地標：村莊、教堂與鐘樓、城堡、燈塔、雪山腳下的營地、叢林神殿、風車、熱氣球、漂浮島與瀑布、軌道懸空處自動架設的木棧橋。
  - 水：溪流、瀑布與池塘照方塊遊戲的規則從泉水流開；島西側有一片從岸上看得到的淺海珊瑚礁。
  - 光源白天像裝飾、夜晚與隧道裡才照亮四周；樹葉有鏤空，玻璃半透明。
  - 軌道周圍會挖空並鋪碎石，三種 spline 下方塊、植物與水都不會碰到列車。
- `Scenery` 關閉時是原本的平坦草地島，用來編輯自己的軌道。
- `Grand Tour` 的海底段：環形閘門、珊瑚礁、海藻林、岩拱、遺跡、沉船與水晶隧道；海裡有魚群、鯊魚、海龜、魟魚、鯨魚與水母。鏡頭在水下時有 caustics、光束、頭燈光錐、微粒與氣泡，抬頭看得到水面的 Snell 窗。
- 水面：Gerstner 波加上捲動噪點，白浪只在部分區域出現；倒影先做螢幕空間反射，沒打中時退回平面反射。
- `Rain` 開啟下雨：天空轉陰、出現雨絲與水面漣漪，雨淋得到的地方逐漸變濕，地面水窪會反射景物；屋簷下、樹下較乾，隧道與屋內不濕。關閉後慢慢變乾。

### 材質包

島上的方塊與植物貼圖可以在執行中切換，像方塊遊戲換資源包一樣：`World` 面板最下面的按鈕顯示目前用的材質（例如 `Textures: Built-in`），按下去的清單裡選 `Built-in`（內建）或一個材質包，畫面立刻換上，不需要重新建島。

- 放材質包的位置：`RollerCoasters.exe` 旁的 `texturepacks/` 資料夾（建置與安裝時會建立空的資料夾），或 exe 旁的 `data/texturepacks/`。每個 `.zip` 或資料夾就是一個材質包，清單依名稱列出，每次打開清單都會重新讀資料夾，所以程式開著時放進去的材質包也會出現。清單裡的 `Open texturepacks folder` 會用檔案總管打開這個資料夾（沒有就先建立），直接把下載的 zip 拖進去；`Open pack...` 會開 Windows 檔案總管的「開啟」視窗，挑放在任何地方的 `.zip` 或資料夾裡的 `pack.mcmeta`。
- 讀得懂兩種格式：
  - 方塊遊戲的資源包（Java 版格式）：`assets/minecraft/textures/block/*.png`，較舊的資源包是 `textures/blocks/`；包在 zip 裡多一層資料夾也可以。依方塊名稱對應到島上的方塊（草地、泥土、石頭、圓石、沙、礫石、雪、原木與樹葉、木板、陶土、礦石、花草等），灰階的草地、樹葉、蕨類和藤蔓會照方塊遊戲的方式染成綠色；動畫材質（熔岩等）取第一格；16×、32×、64× 等解析度都可以，最大用到 256×256。
  - 本程式自己的格式：`textures/<名稱>.png`，名稱見 `src/TexturePack.cpp` 的對照表（例如 `grass_top`、`stone`、`leaves_oak`），每一種貼圖都能換，包含方塊遊戲沒有對應的（窗戶、門、水晶、秋色樹葉、竹子）。
- 島上每一種方塊都盡量用材質包裡有的方塊來畫：資源包沒有對應圖片的，改用最接近的方塊代替，例如秋色樹改用染成橘色的橡樹葉、窗戶用材質包的玻璃（半透明，看得到屋內）、門用橡木門、水晶用海燈籠、花瓣用粉紅花瓣、竹竿與竹梢用竹子方塊與竹葉排成程式畫竹子的方式、沒有紅樹林或櫻花的舊版材質包用染色的橡樹葉。所以用完整的材質包時，島上不會出現材質包以外的方塊（Classic Faithful 32x 換掉全部 73 種）。材質包裡真的沒有的貼圖才維持內建，例如有些材質包沒有水的圖片（水沿用遊戲預設），這時島上的水維持內建。海底世界也一起換：沙、石頭、岩石隧道（深板岩）、遺跡的苔石磚與雕紋石磚、海晶石與暗海晶石、各色珊瑚塊、海燈籠、紫水晶、金塊、海帶、海草、珊瑚扇與海鞘都用材質包的圖；海底的每一種方塊與植物都是方塊遊戲有的，所以全部換得到（生物不在此列）。軌道也換：枕木用材質包的雲杉木板、鋼軌用鐵塊；風車的軸與葉框用橡木、帆布用白色羊毛，熱氣球用各色羊毛、橡木繩與木板吊籃。只有生物（動物、魚、水母）、列車、雲與天空不換。
- 滑鼠停在選單上可以看到這個材質包換了幾種貼圖。讀不到任何可用貼圖的材質包會跳出提示，選單回到原本的選擇。
- 材質包是使用者自己的檔案，不納入版控，也不隨程式散布；請遵守各材質包的授權。

個人軌道請存 `data/`，備份存 `backups/`，兩者均不納入版控。
