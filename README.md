# RollerCoasters

電腦圖學課程的 Windows 桌面過山車編輯器，使用 C++、FLTK 1.3.5 與 OpenGL。

## 建置與啟動

安裝 Visual Studio 2022 或更新版本（例如 2026）的 **使用 C++ 的桌面開發**（MSVC、Windows SDK、C++ CMake tools），以及 PowerShell 7.4 以上版本。

最簡單的方式：clone 後在 Visual Studio 選「開啟資料夾」（或在檔案總管對資料夾按右鍵「使用 Visual Studio 開啟」），
Visual Studio 會讀取 `CMakePresets.json`，選 `Visual Studio (any version) / x64` 與 `Debug`，啟動項目選 `RollerCoasters.exe` 後按 F5。
VS Code 搭配 CMake Tools 擴充也一樣選這個 preset。這個 preset 不綁定 Visual Studio 版本，由 IDE 自行載入已安裝的 x64 編譯器。

命令列建置與完整檢查，以下命令均在此 repository 根目錄執行：

```powershell
pwsh -File scripts/setup-tools.ps1
pwsh -File scripts/check.ps1 -Stage build -Config Debug
./out/build/windows/Debug/RollerCoasters.exe
```

目前支援 Windows x64 的 MSVC 與 clang-cl。隨附的 `.lib` 不支援直接切換 Linux、MinGW 或 ARM。
工具版本與官方下載的 SHA256 固定於 `tools.json`；檢查腳本使用原生 CMake／clang-format。

### 使用 Clang

同樣需要 Visual Studio C++ 工具與 Windows SDK；檢查腳本會自動載入 x64 開發環境。

```powershell
pwsh -File scripts/setup-tools.ps1 -WithClang
pwsh -File scripts/check.ps1 -Stage all -Compiler clang -Config Debug
pwsh -File scripts/check.ps1 -Stage all -Compiler clang -Config Release
./out/build/clang/Release/RollerCoasters.exe
```

只編譯可將 `-Stage all` 改為 `-Stage build`。MSVC 與 Clang 使用獨立的建置目錄。

## 操作

程式一開啟就是展示模式：自動載入 `Grand Tour` 路線並切到 `Train` 相機，列車停在上岸處，按 `Run` 開始行駛（`Run` 預設不開）。
想自己編輯軌道時按 `Reset`（回到平坦草地島、顯示控制點、World 相機），想回到展示按 `Grand Tour`。

- `Grand Tour` 是一條 49 個控制點的長路線，繞行整座方塊風島嶼後潛入海底再回來：
  從海上飛向村莊（風車、小屋、麥田、路燈）→ 沿雪山岩壁螺旋爬升，跨過從山上一路跌進海裡的溪流瀑布 →
  從山頂俯衝，掠過漂浮島與它的長瀑布 → 鑽進彩色黏土地層的峽谷，貼著海水從瀑布旁穿過 →
  越過熔岩河，爬上火山並從火山口的熔岩湖上方飛過 → 高架橋跨過自己的軌道 → 穿過有礦石、燈籠與水晶的岩山 →
  經過巨大蘑菇與櫻花林回到草原，接著出海入水走完海底段。
- 相機：`World`（自由環繞）、`Train`（第一人稱，視角略微朝下，爬坡時仍看得到地面）、
  `Chase`（沿軌道跟在最後一節車廂後上方，看得到整列火車與揮手的乘客；彎道和隧道裡也不會穿進岩壁）、`Top`（正上方，整座島完整放進畫面，不畫雲）、`Fly`（觀察者模式，見下）。
- World：觸控板雙指移動旋轉（滑鼠滾輪左右傾斜也可）；在空白處單指（左鍵）拖曳、Shift + 左鍵拖曳或右鍵拖曳也可旋轉。
- 平移：Alt 或 Shift + 雙指捲動；Alt + 在空白處左鍵拖曳或 Alt + 右鍵拖曳。
- 縮放：滑鼠滾輪向上放大、向下縮小；觸控板雙指張開放大、捏合縮小。觸控板可以一邊移動雙指旋轉、一邊捏合縮放；拖曳旋轉或平移時也能用滾輪縮放。
- 重設：Shift + 左鍵雙擊或右鍵雙擊。
- Train（坐在列車上）：可以轉頭看四周，視線跟著列車前進與轉彎。
  - 轉頭：在畫面上用左鍵或右鍵拖曳（往右拖看右邊、往上拖看上面），觸控板單指按住拖曳或雙指移動也可以（雙指時畫面跟著手指走，和 World、Fly 一樣，放開就停）。左右可以轉一整圈往後看，上下最多 85 度。
  - 回到正前方：雙擊畫面，或按 R／Home（R 依實體按鍵位置讀取，開著注音也有效）。每次切換到 Train 都從正前方開始。
- Fly（觀察者模式，操作仿照方塊遊戲的觀察者模式）：每次切換到 Fly，都從當下的畫面接續，畫面不跳動；World、Train、Chase 都一樣（Train 的傾斜會擺正，因為 Fly 保持水平線），從 Top 切換則在島中央上方往下看。
  - 滑鼠看：在畫面空白處點一下，滑鼠游標隱藏，移動滑鼠（或在觸控板上滑一根手指）直接轉視角；按 Esc 放開滑鼠。點到控制點仍是選取與拖曳。
  - 移動：按住 W／A／S／D 水平前後左右（低頭時也不會鑽進地面）、空白鍵上升、Shift 下降（E／Q、Page Up／Page Down 也可以）；按住 Ctrl 加速 2.5 倍。
  - 輸入法：Fly 模式會暫時關閉這個視窗的輸入法（例如注音），離開 Fly 自動恢復；W／A／S／D、空白鍵、Shift、Ctrl、E／Q、F、`Home`，以及編輯用的 G、R 依實體按鍵位置讀取，所以中文輸入法或其他鍵盤配置下也能飛。
  - 速度：滑鼠滾輪往上變快、往下變慢；也可用 +／- 鍵或 `Camera` 面板的 `Fly` 滑桿（每秒移動單位）。
  - 視野：`Camera` 面板的 `FOV` 滑桿調整垂直視野（30–120 度，預設 70 度），同時套用到 World、Train、Chase 與 Fly；Top 是正交投影，不受影響。
  - 其他看法：右鍵拖曳、方向鍵、觸控板雙指移動（放開手指就停，不會慣性旋轉）。
  - 觸控板：雙指張開／捏合（或 Ctrl + 捲動）沿視線前進後退，可以一邊轉頭一邊前進；Alt + 雙指移動左右、上下平移。
  - 找方向：畫面中央有準星；地面延伸到地平線。按 F 平滑轉向列車，按 `Home` 回到 World 視角位置（`R` 留給傾斜控制點）。
  - 範圍：相機最低可以飛到 y = −200（可以鑽到地面以下看潛入地底或海底的軌道，從下方也看得到地面），最高 600，且不會離場景中心超過 1000 單位。
- 控制面板在視窗右側，外觀仿 3D 建模軟體的屬性編輯器：深灰面板、圓角灰色按鈕，開啟或選取的項目是藍色。由上到下六個面板：
  `Ride`（Run、前後步進、ArcLength、Speed）、`Camera`（World／Train／Chase／Top／Fly、Fly 速度與 FOV）、
  `Track`（Spline Type、Edit、Add／Delete Point、Load／Save／Reset、R±X／R±Z）、`Transform`（選取控制點的 X／Y／Z，可直接輸入）、
  `Lighting`（Light+、Shadows、Headlight、Bloom、SSAO、Time）、`World`（Water、Rain、Scenery、Grand Tour）。Load／Save 讀寫軌道文字檔。
- 編輯控制點（先開啟 `Edit`，World 與 Top 相機）：`Edit` 關閉時控制點不顯示也不能選取。左鍵點選，選到的控制點變橘色並出現移動把手。
  - 拖紅／綠／藍箭頭沿 X／Y／Z 軸移動，拖小方塊在該平面內移動，直接拖控制點則平行於畫面移動。
  - 鍵盤操作與 3D 建模軟體相同：`G` 移動、`R` 傾斜（改變控制點的上方向），之後按 `X`／`Y`／`Z` 鎖定軸，`Shift` + `X`／`Y`／`Z` 鎖定另外兩軸的平面；
    左鍵或 Enter 確定，右鍵或 Esc 取消並還原。按住 `Ctrl` 以 1 單位（傾斜時 5 度）吸附。
  - `Shift` + `D` 複製控制點並立刻移動，`Delete` 或 `X` 刪除，`Ctrl` + `Z` 復原上一次變更（再按一次重做）。
  - 在 Fly 相機下編輯：飛行鍵（W／A／S／D、空白鍵、Shift、Ctrl、E／Q）一律用來飛行，不會觸發編輯。`G`、`R`、`Ctrl` + `Z` 照常；
    複製改用 `Alt` + `D`（`Shift` + `D` 是下降加右移，`Ctrl` + `D` 是加速右移），刪除只用 `Delete`（`X` 在 Fly 下不刪點，避免飛行時誤按）。
    按 `G`／`R` 開始編輯時相機會停住、滑鼠鎖定解除，讓控制點跟著滑鼠走，`Shift` + `X`／`Y`／`Z` 也能鎖定平面；結束後仍按著的飛行鍵會繼續飛。
  - 數字鍵盤 `1`／`7`／`0` 切換 World／Top／Train 相機。畫面左上角會顯示目前相機、選取的控制點與操作中的數值。
  - 控制點是編輯輔助，不投射陰影。
- 光影：`Light+` 開啟 shader 逐像素光照與 shadow map 陰影，關閉即回到原本固定管線畫面。
  `Shadows`、`Headlight`（火車頭燈）、`Water`（島外海面波浪、反射與折射）、`Bloom`（泛光與 god rays）、`SSAO` 可個別開關；
  `Time` 滑桿 0–24 時移動太陽與月亮：日出、日落時陽光轉成金橘色，地平線朝太陽一側是橘金、另一側是粉紫，雲底被染色，海面有金色倒影；夜晚有方形月亮與星空，場景由偏藍的月光照亮，最容易看到頭燈、窗戶與燈籠。顯卡不支援時自動退回原本畫法。
- 列車是方塊風蒸汽火車頭拉著五節木頭礦車，每節各自沿軌道轉向。
  - 火車頭：比礦車大一號（1.3 倍），紅色鍋爐配黃銅箍與汽包、黑色煙箱、煙囪、發光頭燈，每邊三個動輪與連桿，綠色駕駛室配灰色屋頂。
    司機和礦車乘客一樣大、坐一樣高，頭和揮動的手都在屋頂下。整台車是剛體，不會隨風擺動。
  - 礦車：木板車廂、深色角柱與頂框、鐵箍、前方的小銘牌，車底有車輪與導輪；最後一節有紅色尾燈。
  - 每節礦車只坐一位乘客，座位在中間且墊高，上半身和舉高揮動的雙手露在車廂外，手不會卡到車壁或隔壁的人。
  乘客是方塊人：頭、身體、雙手、雙腳各一個方塊，臉用方形像素畫出，膚色、髮色與衣服各不相同，雙手舉高揮動。
- `Scenery` 開啟時，島寬約 500 單位，以 2.5 單位方塊堆成（約 220×220 格、雪山最高約 180 單位），海岸線不是方形，有海灣與岬角；所有貼圖都在程式裡畫出：
  - 尖峭雪山：多條尖銳的山脊與岩峰，下層是雲杉林與雪地，高處雪原上有淡藍的冰刺；軌道沿山壁挖出的平台螺旋而上。
  - 惡地峽谷：紅、橘、黃、白、棕的黏土地層，谷底切到海平面以下，所以海水（含倒影與波浪）會流進峽谷；台地上的水池溢流成瀑布。
  - 火山：玄武岩山體、沿熔岩河岸與火山口邊緣的岩漿塊（深紅褐石塊間的橘黃發光裂縫）、火山口的熔岩湖，以及兩條流到海邊的熔岩河；熔岩會把附近的方塊照成暖色。
  - 岩山：石頭裡露出煤、鐵、金、鑽石礦，隧道段有燈籠與水晶照明。
  - 草原：橡樹、白樺、櫻花樹、秋色樹（皆為方塊樹）、成片的花與草、池塘、巨大蘑菇，還有會走動的羊、豬、牛。
  - 方塊貼圖：全部在程式裡畫成 32×32 的經典方塊風格（圓石、礫石、木板、樹皮、樹葉、礦石都有輪廓與明暗），海底方塊同一風格；沒有使用任何外部材質包。
  - 西方外海有一座沙岸與草地丘陵的小島，黃昏時夕陽落在它旁邊。
  - 東北方隔著海峽是一塊新大陸：靠海峽的一半是紅樹林沼澤（架在氣根上的紅樹、垂下的藤蔓、泥灘裡的水窪），另一半是竹林丘陵（高聳的竹子與少數掛著藤蔓的大樹）。`Grand Tour` 在陸地段最後從主島北岸出海，沿新大陸外側繞過竹林、低空掠過沼澤，再經跨海峽的長棧橋回到主島。
  - 地標：瀑布附近的海岬上有一座城堡（城牆與城垛、四座角塔、城門、中庭、木石主堡與高塔，窗戶夜晚會亮），西岸岬角有紅白條紋的燈塔與守塔人小屋（燈夜晚會亮），村莊有石造教堂與鐘樓，外圍有麥田與水渠；島中央是一片櫻花樹林，圍著一座湖（湖中小島種著櫻花樹、有木碼頭），地上鋪滿花瓣，空中有花瓣飄落；旁邊是巨大的橡樹和一片各色花海；村莊門口有夜晚會亮的南瓜燈；雪山腳下的雲杉林裡有一處營地（原木小屋、營火、路燈與南瓜燈，軌道從營地上方經過）；惡地台地上有風蝕岩柱與黃橘色環帶的藍色溫泉；夜晚的珊瑚會微微發光。
  - 巧思：跨過瀑布水潭的木橋、漂浮島與瀑布、方塊雲、三顆熱氣球、轉動的風車、夜晚會亮的窗戶與路燈、軌道懸空處自動架設的木棧橋。
  - 島上的溪流、瀑布、池塘、井和麥田水渠都是方塊遊戲式的靜態水方塊：平滑的淺藍色、只有幾條淡淡的橫紋、半透明，看得到後面的河床與岩壁，水面比方塊頂略低。
    水照方塊遊戲的規則從泉水自己流開：能往下就先往下；往旁邊每流一格水位降一級，最多 7 格；每個可流的方向權重從 999 起算，
    4 格內找得到往下的落差就以最短路徑長度為權重，水只往權重最小的方向流。
  - 瀑布：雪山北麓（沒有軌道經過的一側）切出一道朝北的岩石峽谷，4 格寬的溪流從岩石裡流到垂直的石崖邊緣，整片落下約 22 單位，
    落進下方的水潭，瀑布和水潭都是同一種靜態水。水潭接一條 2 格寬的河，沿地勢一階階流到北岸，從島邊落進海裡；
    碰到海面的那一層水改用與海水相近的青藍色。島外圍留了一圈空格子，水才能從島邊落到海面。
  - 漂浮島的泉水從邊緣落成一整格寬的長水柱，落進下方的池塘。
  - 水的位置都選在碰不到軌道的地方，軌道旁、下方與上方都沒有水，也沒有人工擋水方塊。
  - 軌道周圍會挖空（路塹、平台或隧道）並鋪上碎石，三種 spline 下方塊、樹與花草都不會碰到列車。
- `Scenery` 關閉時是原本的平坦草地島（方塊草地加幾棵方塊樹），用來編輯自己的軌道。
- 島的西側、夕陽落下的方向有一片淺海珊瑚礁，離海面只有幾單位，黃昏時從岸上或列車上能透過金粉色的海面看到彩色珊瑚。
- `Grand Tour` 的海底段：穿過環形閘門入水，經過珊瑚礁與巨蚌、海藻林、岩拱、有燈的石柱遺跡與階梯神殿、
  水母群、沉船，從石門進入只靠發光水晶照明的岩石隧道，再穿過環形閘門衝出水面回到島上。
  海底是 5×5×5 方塊組成的世界，所有貼圖都在程式裡畫出；
  軌道周圍會挖空並保留淨空，三種 spline 下方塊與水草都不會碰到列車。
  海水清澈，遠景淡入藍色；鏡頭在水下時有海床光紋（caustics）、從水面射下的光束、頭燈光錐、漂浮微粒與氣泡，
  抬頭可看到水面的 Snell 窗與閃爍的太陽。海裡有跟著軌道的魚群、鯊魚、海龜、魟魚、鯨魚與發光水母；小魚成群、朝同一方向沿著軌道游過整段海底路線（一半順向、一半逆向），大魚群與大型生物在開闊的深水區大範圍遊走，不繞圈；每隻都有黑點眼睛。
- 水面：細分網格以 Gerstner 波做頂點位移，多層捲動噪點擾動法線，倒影先做螢幕空間反射（SSR），沒打中時退回平面反射，
  強度依菲涅耳（Schlick）公式隨視角變化。
- `Rain` 開啟下雨：天空轉陰、有雨絲，水面出現雨滴漣漪，地面逐漸變濕（變暗、高光變銳利），水窪會鏡面反射周圍景物；
  關閉後慢慢變乾。岸邊貼近水面的一圈永遠是濕的。

個人軌道請存 `data/`，備份存 `backups/`，兩者均不納入版控。

## 開發入口
