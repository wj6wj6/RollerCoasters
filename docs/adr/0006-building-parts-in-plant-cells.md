# ADR 0006：建築的小構件（樓梯、半磚、活板門、花盆）放在植物格

日期：2026-11-19
狀態：採用

## 背景

島上的建築原本全由整格方塊組成：屋頂是一層層內縮的整塊木板，看起來像階梯金字塔；牆面平坦，窗戶沒有窗台或邊框。方塊遊戲的建築靠樓梯、半磚、活板門與花盆做出斜屋頂、出簷、挑出的樓層與窗台，使用者也要求建築「牆面要有層次、屋頂要有造型、窗戶不要太單調」。

## 決策

- 新增四種植物格構件：`STAIRS`、`SLAB`、`TRAPDOOR`、`POT`，和既有的 `FENCE`、`LAMP` 一樣放在方塊為 `AIR` 的格子。材料、朝向、上下半與外角存在原本給水位與雪層用的 `Grid::level`（一個位元組，`shapeLevel()` 編碼），不增加每格的記憶體。
- `addShape()` 把它們畫成實心方塊批次裡的盒子，因此有光照、陰影與 alpha test（活板門的孔），貼圖照方塊比例對齊，和方塊遊戲一樣。
- 屋頂由 `buildGableRoof()`／`buildHipRoof()` 產生，窗台與花盆由 `dressWindows()`、牆腳花圃由 `flowerBeds()` 產生，各建築共用。
- 新增的方塊與貼圖（石磚、青苔石磚、深色橡木原木、雲杉活板門、花盆）都在材質包對照表裡，套用材質包時一起換掉。

## 取捨

- 構件不是不透明方塊：不參與 ambient occlusion，光線可以穿過（和柵欄、燈籠相同）；屋頂下方用方塊填滿，所以屋內不會從屋頂透光。
- 積雪不落在構件上（方塊遊戲的樓梯上也沒有雪層），營地小屋的樓梯屋頂因此不再積雪。
- 樓梯只有直的與外角兩種，沒有內角；目前的山形與四坡屋頂用不到內角。
- 構件和柵欄一樣不算碰撞方塊，但 `rideObstructions()` 仍把植物格算進列車淨空檢查，建築也照舊只蓋在整體淨空之外。
