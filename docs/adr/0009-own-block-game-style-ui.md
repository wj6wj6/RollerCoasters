# ADR 0009：介面自己用 OpenGL 畫成方塊遊戲風格

日期：2026-11-21
狀態：採用

## 背景

使用者要整個換掉 FLTK，介面做成像 Minecraft 那樣：全畫面、ESC 開設定畫面、底部快捷欄切換相機與編輯工具（2026-11-19 在 project thread 選定）。Minecraft Java 版的按鈕、滑桿與文字都是遊戲自己用貼圖畫的，視窗與輸入交給 GLFW（LWJGL）。課程規定可以使用其他 UI 工具，但外部函式庫要先問助教。

可選的做法：

1. Dear ImGui 再換外觀：元件齊全，但外觀是桌面工具風，要做成像素風需要大量改樣式，而且多一個外部函式庫要請助教同意。
2. 自己寫一個小型即時模式介面：需要的元件不多（按鈕、開關、循環按鈕、滑桿、清單、文字），外觀完全可控，沒有新的依賴。

## 決策

採用 2，放在 `src/Ui/`：

- `PixelFont`：自己畫的 ASCII 像素字型，比例寬度，字與字之間空一欄，加一像素的陰影。
- `UiAtlas`：字型與元件貼圖在程式裡畫成一張 256 x 256 RGBA atlas，元件以九宮格伸縮。外觀是本專案自己的石板灰風格，不使用任何遊戲的素材。
- `Gui`：即時模式。每幀由畫面程式碼呼叫元件函式，元件同時產生 quads 並回報是否被使用；跨幀只保留滑鼠狀態與正在拖曳的滑桿。按鈕在按下時觸發（照方塊遊戲），循環按鈕左鍵往後、右鍵往前。`feed()` 回報事件是否落在介面上，讓 3D 視圖不會同時收到。GUI 縮放照方塊遊戲的 Auto：最大的整數倍，且至少留下 320 x 240 單位。
- `GuiGl`：唯一碰 OpenGL 的部分，以固定管線畫出 quads，和專案其他繪圖方式一致。

這個 PR 只加入元件並先用在載入畫面的文字（取代 `gl_font`）；ESC 選單、快捷欄與 GLFW 主迴圈在下一個 PR。

## 取捨

- 只有 ASCII：介面文字維持英文（和現在的 FLTK 面板相同）。之後若要中文，需要另外的字型來源。
- 沒有鍵盤焦點與 Tab 切換；方塊遊戲的選單以滑鼠為主，需要時再加。
- 即時模式每幀重建 quads，元件數量很少（數十個），成本可以忽略。
