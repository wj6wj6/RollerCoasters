# ADR 0021：海面的 Height Map 與 Wave Equation 模式

日期：2026-11-26
狀態：採用

## 背景

P4（Water Surface）的 Water surface 評分有三項：Sine waves（20）、Height maps（10）、Wave equation（30）。海面原本只有 8 組 Gerstner 波（vertex shader 推動 160 × 160、每格 3 單位的網格），算是 Sine waves；另外兩項沒有。課程附了 `HeightMap\000.png`…`199.png`：200 張 512 × 512 灰階、可無縫鋪排、首尾相接循環的海面高度圖。期末專題清單要求新模式可切換，預設畫面不能退步。

## 決策

- 新設定 `SceneSettings::waves`（`World` →`Waves`、`V`、`--waves`）：`Gerstner`（預設，原樣不動）、`Height Map`、`Wave Equation`。
- 純計算放 `src/WaterWaves.*`（沒有 OpenGL，`WaterWavesCheck` 測試），GPU 部分放 `src/WaterSurface.*`，由 `PostEffects` 擁有並在畫海面時使用。
- Height Map：
  - 高度圖做成 `GL_R8` 的 3D 貼圖（寬、高是一張圖，深度是時間），三軸 `GL_REPEAT` 加三線性過濾與 mipmap：圖自然鋪滿整片海，影格之間平滑內插，序列播完接回開頭。
  - 依 P4 規格的 `H(x, z, t) = Σ b(Aᵢx + Bᵢ, Aᵢz + Bᵢ, Atᵢt + Btᵢ)` 疊三層：Aᵢ 是旋轉加縮放（52、23、9.5 單位一張，方向 20、83、149 度），Atᵢ 是 1/9、1/6.3、1/4.1 秒，各乘振幅 2.4、0.9、0.3 並扣掉圖的平均灰階；大小、方向與速度不成簡單比例，看不出格子。整片海的高低差約 0.5 單位，和 Gerstner 相近。
  - vertex shader 依頂點所在格子的大小選 mip（`texture3DLod`），fragment shader 以 0.2 單位外兩點的高度差算法線，細節不受網格密度限制。
  - repo 內放 `assets/heightmaps/waves.png`：每隔一張取、2 × 2 平均縮成 256 × 256，10 × 10 拼成一張（2.2 MB，原始 200 張約 14 MB）；時間軸的內插補回少掉的影格。exe 旁有課程的 `HeightMap\` 資料夾時改讀原始 200 張。兩者都讀不到時用程式產生的替代圖，模式仍可用。
- Wave Equation：
  - 1024 × 1024 格、每格 0.5 單位（512 單位見方，約等於細網格的範圍），兩張 `GL_RG32F` 貼圖（r：現在的高度，g：上一步）與各自的 FBO 輪流讀寫。
  - 一步是一個全畫面 pass：`h' = h + d(h − h₋₁) + k(四鄰之和 − 4h)`，`k = (cΔt/Δx)² ≈ 0.054`（c = 7 單位／秒，Δt = 1/60 秒，穩定條件 k < 1/2），d = 0.996 是阻尼；最外 48 格阻尼加大成吸收層，波不會從邊界反彈。固定步長，一幀最多補 4 步（掉幀時水變慢而不是爆掉）。
  - 網格中心跟著海面細網格的中心（鏡頭前方視線落到海面的地方），以整格移動，移動量併在下一步的取樣位移裡，漣漪留在世界原處；跳太遠就清空。
  - 擾動是 cosine 形的凸塊，一個 pass 最多加 8 個：`B` 或 Fly 右鍵丟石頭（視線與海面的交點）、列車每節車廂穿過海面時濺起一圈、貼著水面跑時拖出尾流（沿路一連串往下壓的凹陷，自然形成船首波與尾跡）、下雨時鏡頭 70 單位內每秒約 60 滴。
  - 頂點高度取格子範圍的平均（避免細漣漪讓粗格抖動），法線取相鄰格的高度差；同時保留較弱的細碎噪點漣漪。
- 兩種新模式用另一個網格：256 × 256 格、從中心 0.85 單位漸寬到邊緣 4 單位（`x = R(a s + (1 − a) s³)`），沒有接縫，每個頂點帶自己的格寬給 vertex shader 選 mip。Gerstner 仍用原本的網格。
- 海面 shader 的 3D 與 2D sampler 在程式建立時就指定到第 4、5 個 texture unit：兩種類型的 sampler 留在同一個 unit 會讓之後每次用這個 program 的 draw call 都失敗（例如只畫島上的水時）。

## 結果

- Linux（Xvfb + llvmpipe）以正式的 `PostEffects`／`AdvancedLighting`／島與海床畫出三種模式、丟石頭、列車衝入海面與水下仰望的畫面，見 PR。
- 每幀成本：Height Map 多 9 次 3D 貼圖取樣／像素；Wave Equation 每步一個 1024² 的 pass（4 次取樣），一幀最多 4 步。Windows 實機的效能尚未量測。

## 取捨

- 沒有把波動方程網格放大到整片海：512 單位已涵蓋看得清楚的範圍，更遠處本來就被距離淡化成平面。
- 雨與石頭共用同一個擾動形狀，雨滴半徑 0.9 單位比真實雨滴大很多，看得到的是網格解得出的漣漪；更細的雨點仍由原本的程序式雨圈補上。
