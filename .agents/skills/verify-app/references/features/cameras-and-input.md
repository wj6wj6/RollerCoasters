# 相機與輸入

## 有什麼

- `World`（環繞）、`Train`（第一人稱，可轉頭）、`Chase`（跟在車尾後上方）、`Top`（正交俯視）、`Fly`（觀察者自由飛行）。
- 滑鼠、滾輪（直接讀 Windows 原始位移）、精準觸控板（Raw Input 加 Direct Manipulation）、鍵盤（Fly 與 Train 依實體按鍵位置讀取，輸入法開啟時仍有效）。
- `FOV` 滑桿同時套用到所有透視相機；`Fly` 滑桿調整飛行速度。

## 怎麼到達

`Camera` 面板的五個按鈕；數字鍵盤 `1`／`7`／`0` 切換 World／Top／Train。操作細節見 README「操作」。

## 怎麼用 CLI 驅動

- 成功：`smoke -Only cameras`（`--camera world|train|chase|top|fly`）。
- 錯誤：`smoke -Only usage-bad-camera`（未知的相機名稱回 2）。
- 不同軌道位置：`screenshot -Name chase-tunnel -AppArgs '--camera','chase','--u','40'`。
- 拖曳、觸控板、輸入法、切換相機時的接續沒有 CLI，只能手動檢查；相機數學另有 `GestureMotionCheck`、`FlyCamCheck`、`HeadLookCheck`、`TwoFingerGestureCheck`、`EditKeysCheck`。

## 容易騙過檢查的假象

- `--camera fly` 是從 Train 畫面切過去的；「切換時畫面不跳動」要看前後兩張截圖是否接續，單張截圖看不出來。
- CTest 用的是合成的 FLTK 事件，不是真的 Windows 觸控訊息；觸控板手感一定要在實機上試。
- Chase 在直線段看起來正常，彎道和隧道裡才會穿進岩壁，所以要多換幾個 `--u` 位置。

## 手動檢查

**World**
- 按 Grand Tour 後切到 World：從島外斜上方看到整座島，不會卡在山壁前；滾輪縮到最遠時，島的遠側、火山與遠方海面都完整畫出。
- 雙指旋轉平滑、水平線穩定，手指停下時畫面立即停止；捏合／張開與 Ctrl + 滾輪的縮放方向正確且連續。
- 同一個手勢中邊移動邊捏合時，旋轉與縮放同時發生；只捏合時視角不轉動、只移動時不縮放，手指靜止時畫面不抖；放開後旋轉有慣性並自然停止。
- 右鍵或空白處左鍵拖曳時用滾輪縮放，畫面不跳動。
- 實體滑鼠滾輪向上放大、向下縮小，每格平滑縮放約 10%、視角方向不變；左右傾斜滾輪平滑旋轉。
- 在空白處左鍵拖曳可旋轉，點到控制點仍可拖曳控制點；Alt／Shift 平移與重設正常，重設後沒有殘留動畫。
- 主控台沒有 `[touchpad]` 診斷訊息。

**Top 與 Chase**
- Top：不論視窗寬或窄，主島與東北陸地都在畫面內、上下不被切掉，雲不擋住地圖；Top 中可點選並拖曳控制點，從 Top 切到 Fly 時畫面不跳動。
- Chase 沿軌道跟在車尾後方，看得到前導車、五節車廂與乘客，彎道與隧道中不穿進岩壁。

**Fly**
- 分別從 World、Train、Chase 切到 Fly，畫面都從當下視角接續、不跳動（只有 Train 的傾斜會擺正）；從 Top 切換時改從島中央上方往下看。
- 點畫面空白處後游標隱藏，移動滑鼠（含觸控板單指）直接轉視角，游標不會跑出畫面；Esc 放開滑鼠且視窗不會關閉，切到別的視窗時自動放開。
- WASD 水平移動、空白鍵／Shift 升降、Ctrl 加速，放開按鍵立即停止；滑鼠滾輪改變速度，`Camera` 面板的 `Fly` 滑桿同步；切到其他視窗再回來時相機不會自己漂移。
- 開著注音（中文模式）切到 Fly：不會跳出選字視窗，W／A／S／D、空白鍵、Shift 正常飛行；切回 World 後輸入法恢復。
- 畫面中央有準星、沒有操作提示文字；低頭按 W 時保持水平；遠離場景時地面延伸到地平線，地面與棋盤格之間沒有閃爍；F 平滑轉向列車，轉向中拖曳可立即接手；按住 Shift 可一路降到 y = −200，從地面下方仍看得到地平線地面與棋盤格。
- 觸控板雙指移動轉向、放開後不慣性旋轉；捏合／張開前進後退、Alt + 捲動平移（Shift 是下降）；`Fly` 滑桿與 +／- 鍵同步；`Home` 回到 World 視角；Fly 模式仍可點選並拖曳控制點。
- `FOV` 預設 70，拖動時 World、Train、Chase、Fly 的視野都立即改變（Top 不變）。

**Train**
- 左鍵或右鍵拖曳可轉頭（往右拖看右、往上拖看上），可轉一整圈往後看，上下停在約 85 度不會翻轉；觸控板雙指移動也能轉頭、放開即停。
- 列車 Run 時轉頭後，視線仍跟著列車；雙擊、R（開著注音也有效）或 Home 回到正前方；切到其他相機再切回 Train 時從正前方開始。
- Train 視角點畫面不會選到看不見的控制點。
