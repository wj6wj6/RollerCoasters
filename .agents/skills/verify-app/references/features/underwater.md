# 海底段與海洋

## 有什麼

- `Grand Tour` 的海底段：環形閘門、珊瑚礁與珊瑚丘、海藻林、岩拱、遺跡與階梯神殿、沉船、只靠水晶照明的岩石隧道。
- 海洋生物：魚群、鯊魚、海龜、魟魚、鯨魚與水母，位置是時間的函數。
- 水下效果：caustics、光束、頭燈光錐、漂浮微粒與氣泡、水面的 Snell 窗。
- 島西側從岸上就看得到的淺海珊瑚礁。

## 怎麼到達

`Grand Tour` 用 `Train` 相機跑完海底段；`Water` 開啟。

## 怎麼用 CLI 驅動

- 成功：`smoke -Only world-underwater`（`--u 10`、Train 相機）。
- 其他位置：`screenshot -Name wreck -AppArgs '--camera','chase','--u','<值>'`；海底段是控制點 0–25。
- 黃昏看珊瑚礁：`screenshot -Name reef -AppArgs '--time','17.75','--camera','world'`。
- 淨空由 `OceanRideClearanceCheck` 測試。

## 容易騙過檢查的假象

- 水下效果需要 shader 路徑；`doctor` 回報 `post effects` 失敗時，水下畫面只剩霧色，但截圖檢查仍可能通過。
- 入水與出水的切換只發生在一瞬間，單張截圖拍不到。

## 手動檢查

- 入水與出水時畫面切換正常；水下看得到遠處的岩石與遺跡，有光束、微粒、氣泡與各種海洋生物。
- 隧道內變暗，只剩水晶與頭燈的光；列車不會穿過方塊，水草與珊瑚不碰到鐵軌。三種 spline 都試一次。
- 經過沉船時：船身是木板、船頭是尖的，甲板破洞看得到船艙，船尾樓有欄杆，主桅是斷掉的短樁，船上沒有一排橫放的原木。
- `Time` 調到約 17:45，從島西岸朝夕陽看：淺海裡看得到粉紅、紅、橘、紫、黃色的珊瑚塊，海面有金色倒影，珊瑚沒有露出水面。
- 珊瑚礁是一座座同色為主、中間較高的珊瑚丘，丘與丘之間露出沙地；鐵軌兩旁是沙地與珊瑚扇、海草，不會有被切平、顏色像棋盤格一樣交錯的珊瑚地板。淺海珊瑚礁是一塊塊的色塊，中間與周圍有不少沙地。
- 從水下往上看海面，大部分看得到天空、雲與島，只有接近水平處才轉成藍色，波紋讓畫面輕輕晃動、不會碎掉。
- 光柱（ADR 0019）：朝太陽往上看，光柱是幾道粗細不一、帶藍綠色的光束，交會在水面上看到的太陽（只有一個太陽），不是一大把細白線；靠近水面清楚，越往海底越淡；背對太陽時很淡。看幾秒，光束會慢慢移動變形。`Time` 調到 7–8 時，光柱仍偏陡（光進水會折射）。記錄水下幀率（F3）。
- 夜晚珊瑚微微發光。
- 海鞘是立體的小方塊模型：一格 1–4 顆（4 顆時排成方塊遊戲的位置，不排成一列），頂上有兩片交叉的發光小芽；套材質包時用材質包的 `sea_pickle` 圖，側面、頂面與小芽各取對的區塊。
