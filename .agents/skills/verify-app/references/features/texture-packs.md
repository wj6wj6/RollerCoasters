# 材質包

## 有什麼

- 選單 `World` 的 `Texture Pack` 清單：`Built-in` 與 `texturepacks/` 中找到的材質包，清單右上方是目前材質包換了幾種貼圖；下方 `Open Pack Folder`。把材質包（zip 或資料夾）拖進遊戲視窗會複製進 `texturepacks/` 並列在清單裡，點它才套用；放在其他地方的材質包也可用 `--pack` 啟動時套用。
- 支援兩種格式：方塊遊戲的資源包（Java 版）與本程式的 `textures/<名稱>.png`；zip 或資料夾都可以。
- 套用後換掉島上、海底、枕木、鋼軌、風車帆布與熱氣球的貼圖，不重建島嶼。

## 怎麼到達

Esc →`World`；材質包放在 exe 旁的 `texturepacks/` 或 `data/texturepacks/`。

## 怎麼用 CLI 驅動

- 環境：`doctor` 列出找到的材質包，以及每個能換掉幾種貼圖；打不開的材質包會顯示 `FAIL`。
- 成功：`screenshot -Name pack -AppArgs '--pack','<zip 或資料夾>','--camera','world'`，再用同樣的參數不加 `--pack` 截一張 `Built-in` 對照。
- 錯誤：`smoke -Only pack-missing`（缺少的路徑必須回 1）。
- 空狀態：`texturepacks/` 是空的時候，`doctor` 應顯示 `0 pack(s)` 且通過。
- 解碼與對照由 `TexturePackCheck` 測試。材質包是使用者的檔案，不要提交，也不要放進 PR 附件。

## 容易騙過檢查的假象

- 只換了島上的貼圖、漏了海底或枕木時，從 World 遠看幾乎看不出差別；要在海底與近處各截一張。
- 清單的選取列可能更新了，畫面卻沒有換；一定要比對前後兩張截圖。
- 選到壞掉的材質包時應該顯示 `Not a texture pack` 並回到原本的選擇，不能停在半套用的狀態。
- 清單的捲動與點選沒有 CLI，`--screenshot` 測不到，必須手動試。

## 手動檢查

- `Open Pack Folder` 用檔案總管打開 exe 旁的 `texturepacks/`（路徑有中文或空白也能開）。
- 把一個 zip 材質包（或資料夾）放進去，不必重開程式，切回遊戲視窗（或關掉再打開 `World` 畫面），清單就列出它。
- 把一個 zip 材質包、再把一個材質包資料夾拖進遊戲視窗：`World` 打開，清單捲到它並顯示 `Added ...`，`texturepacks/` 多了它的複本；目前用的材質包不變，點它才套用。拖一個不是材質包的 zip：顯示 `Nothing was added`，`texturepacks/` 沒有多出檔案。
- 選它後島上的草地、石頭、樹葉等立刻換掉；秋色樹、窗戶、門、水晶、花瓣與竹子也換成材質包裡最接近的方塊（除非材質包真的沒有，例如沒有水的材質包）。
- 海底的沙、石頭、隧道岩壁、遺跡、海晶石閘門、珊瑚、海燈籠、海帶、海草與海鞘全部換成材質包的圖（只有生物不換）；軌道枕木是材質包的木板、鋼軌是鐵塊；風車帆布與熱氣球是材質包的羊毛。
- 樓梯、半磚、活板門、花盆、門、睡蓮葉、甘蔗、黏土、灰化土與粗泥都換成材質包的圖；灰階的草地與樹葉染成綠色。
- 島上的羊、豬、牛換成材質包 `entity` 資料夾的皮膚（Classic Faithful 32x 這種新版材質包與 Minecraft Classic Edition 這種舊版材質包都要換到），臉、眼睛與斑點落在正確的面上；切回 `Built-in` 時回到內建皮膚。
- 列車的乘客換成材質包 `entity/player/wide/` 的玩家外觀（或舊版的 `entity/steve.png`），礦車用 `entity/minecart`，熔爐礦車用材質包的熔爐方塊；臉、帽子與衣服落在正確的面上。
- 切換時不重建島（不會卡頓數秒）；清單右上方顯示換了幾種貼圖；選回 `Built-in` 恢復原狀。
- 把一個不是材質包的 zip 放進資料夾再點它：遊戲內顯示 `Not a texture pack`，按 OK 回到 `World`，清單回到原本的選擇；壞掉的圖片不會跳出任何系統視窗。
- 目前用的材質包在清單裡是選取的那一列；材質包多於兩個時滾輪可捲動清單，捲到底就停。
- 記錄使用的材質包名稱（不提交材質包本身）。
