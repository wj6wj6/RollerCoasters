# 控制點編輯

## 有什麼

- 開啟 `Edit`（或按 `F4`）後顯示控制點；點選後出現三色移動把手（軸箭頭與平面方塊）；World／Top 也可用中鍵或 `C` 選取游標下的點。
- 新增：快捷欄 `7` 或 `Shift` + `D` 進入放置模式，滑鼠移到軌道上出現黃色預覽點，點下後新點插在點擊處並進入拖曳。
- 鍵盤：`G` 移動、`R` 傾斜，加 `X`／`Y`／`Z` 鎖軸，`Shift` + 軸鎖平面，`Ctrl` 吸附；`Delete`／`X` 刪除。Fly 相機下新增改用 `Alt` + `D`，`X` 不刪點。
- 上一步／下一步：`Ctrl` + `Z`／`Ctrl` + `Y` 或 `Undo`／`Redo` 按鈕，涵蓋所有修改控制點的操作。
- Fly 建造（滑鼠鎖定且 `Edit` 開啟，仿 Minecraft）：左鍵刪準心對到的點、中鍵或 `C` 選取、右鍵在黃點處放新點；`G` 拿起點跟著視角移動，滾輪調整遠近。
- 選單 `Track` 顯示選取點的座標，`X-`／`X+`／`Y-`／`Y+`／`Z-`／`Z+` 每次移動 1 單位。

## 怎麼到達

快捷欄 `6`、`F4` 或選單 `Track` 的 `Edit Points`；World、Top、Fly 相機可以編輯。

## 怎麼用 CLI 驅動

- 編輯前後的狀態：`screenshot -Name before -AppArgs '--track','<檔案>','--scenery','off','--camera','top'`。
- 拖曳、按鍵、新增、取消（Esc／右鍵）與復原都沒有 CLI。它們的數學與鍵位由 `GizmoDragCheck`、`EditKeysCheck`、`TrackInsertCheck`、`TrackHistoryCheck` 測試，實際操作要手動檢查。

## 容易騙過檢查的假象

- `GizmoDragCheck` 只算射線與軸的數學，看不到把手是否畫在控制點上、滑鼠移上去會不會變亮。
- Fly 下的鍵位衝突只在真的按住飛行鍵時出現；表格測試通過不代表事件順序正確。
- 取消後要確認點真的還原了，不能只看把手消失。
- `TrackHistoryCheck` 只測快照本身；某條修改路徑忘了先存快照時，要實際逐步按 `Undo` 才會發現少了一步。
- 新增點時軌道形狀「幾乎不變」：Linear 與 Cardinal 看不出差別，B-spline 才需要反解，所以三種樣條都要試。

## 手動檢查

- 開啟 `Edit`（或按 `F4`，開著注音也有效；再按一次關閉）後才看得到控制點；點選後出現三色箭頭與平面方塊，滑鼠移到把手上會變亮；World／Top 中鍵或 `C` 也能選取游標下的點，不會拖動或轉視角。
- 拖箭頭只沿該軸移動、拖方塊只在該平面移動，選單 `Track` 的座標同步更新；`X+` 等按鈕也會移動控制點。
- `G`、`R` 加 `X`／`Y`／`Z`、`Ctrl` 吸附、Esc／右鍵取消、`Shift` + `D`、`Delete`、`Ctrl` + `Z` 都如 README 所述；World 相機下編輯時不會誤觸發旋轉視角。
- 上一步／下一步：依序新增一點、拖曳、刪除一點、按 R+X、按 `Y+`，再連按 `Ctrl` + `Z`（或 `Undo`）逐步倒回到最初，`Ctrl` + `Y`（或 `Redo`）逐步回來，每一步畫面與選取都正確；沒有可做的步驟時按鈕變灰；只點選控制點不動不會多一步；倒回後做新修改，`Redo` 變灰；`Reset Track` 後按 `Undo` 能找回原本的軌道。
- 新增控制點：Linear、Cardinal、B-spline 各試一次。按快捷欄 `7` 後滑鼠移到軌道上出現黃色預覽點、離開軌道就消失；點下後新點出現在點擊處（軌道形狀幾乎不變）、被選取，按住可直接拖曳；`Esc`／右鍵取消；點空白處仍可旋轉相機。列車停在最後一段時新增前面的點，列車不會跳回起點；Top 相機下也能新增；坐車時按 `7` 會切到 World 相機；Fly 相機下按 `7` 只會鎖定滑鼠進入建造（右鍵放點）。
- Fly 建造（滑鼠鎖定且 `Edit` 開啟）：準心對準控制點出現白框與「Point N」提示，左鍵刪除該點、中鍵或 `C` 選取（開著注音也有效）、右鍵在黃點處放新點並接在黃線所指的軌道段；滾輪調黃點遠近，飛行速度不變；`Edit` 關閉時滑鼠鍵不做事、滾輪調速度；每次放、刪都能 `Ctrl` + `Z` 復原；`Del Pt` 刪點後列車不跳。
- Fly 下按 `G` 拿起準心對到的點（或選取的點）：點立刻跳到準心上、距離不變，畫面不停，轉視角與 W／A／S／D 飛行時點跟著走不跳，滾輪調遠近；再按 `G` 或左鍵放下、`Esc` 放回。
- Fly + `Edit`：選取控制點後 W／A／S／D、空白鍵、Shift、Ctrl、E／Q 仍只會飛行；`R` 傾斜可用，開始時相機停住、游標顯示；期間按 `Shift` + `X` 鎖平面不會讓相機下降；Esc 取消並還原，Enter／左鍵確定，之後按住的飛行鍵恢復飛行、放開即停（不會卡住一直移動）。
- Fly 下 `Alt` + `D` 新增、`Delete` 刪除；`Shift` + `D` 與 `X` 不會新增或刪除；`Home` 回到 World 視角。切回 World 相機後 `Shift` + `D`、`X` 照舊。
- 控制點在地面上沒有影子，快捷欄上方的狀態文字清楚可讀。
- 開啟 `Shadows` 等光影選項後，仍能點選與拖曳控制點。
