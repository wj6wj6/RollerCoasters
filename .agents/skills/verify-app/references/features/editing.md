# 控制點編輯

## 有什麼

- 開啟 `Edit` 後顯示控制點；點選後出現三色移動把手（軸箭頭與平面方塊）。
- 鍵盤：`G` 移動、`R` 傾斜，加 `X`／`Y`／`Z` 鎖軸，`Shift` + 軸鎖平面，`Ctrl` 吸附；`Shift` + `D` 複製、`Delete`／`X` 刪除、`Ctrl` + `Z` 復原。Fly 相機下改用 `Alt` + `D`，`X` 不刪點。
- `Transform` 面板顯示並可直接輸入選取點的座標。

## 怎麼到達

`Track` 面板的 `Edit`；World、Top、Fly 相機可以編輯。

## 怎麼用 CLI 驅動

- 編輯前後的狀態：`screenshot -Name before -AppArgs '--track','<檔案>','--scenery','off','--camera','top'`。
- 拖曳、按鍵、取消（Esc／右鍵）與復原沒有 CLI；它們的數學與鍵位由 `GizmoDragCheck`、`EditKeysCheck` 測試，實際操作要手動檢查。

## 容易騙過檢查的假象

- `GizmoDragCheck` 只算射線與軸的數學，看不到把手是否畫在控制點上、滑鼠移上去會不會變亮。
- Fly 下的鍵位衝突只在真的按住飛行鍵時出現；表格測試通過不代表事件順序正確。
- 取消後要確認點真的還原了，不能只看把手消失。

## 手動檢查

- 開啟 `Edit` 後才看得到控制點；點選後出現三色箭頭與平面方塊，滑鼠移到把手上會變亮。
- 拖箭頭只沿該軸移動、拖方塊只在該平面移動，`Transform` 面板的數值同步更新；直接輸入數值也會移動控制點。
- `G`、`R` 加 `X`／`Y`／`Z`、`Ctrl` 吸附、Esc／右鍵取消、`Shift` + `D`、`Delete`、`Ctrl` + `Z` 都如 README 所述；World 相機下編輯時不會誤觸發旋轉視角。
- Fly + `Edit`：選取控制點後 W／A／S／D、空白鍵、Shift、Ctrl、E／Q 仍只會飛行；`G` 移動、`R` 傾斜可用，開始時相機停住、游標顯示；期間按 `Shift` + `X` 鎖平面不會讓相機下降；Esc 取消並還原，Enter／左鍵確定，之後按住的飛行鍵恢復飛行、放開即停（不會卡住一直移動）。
- Fly 下 `Alt` + `D` 複製、`Delete` 刪除；`Shift` + `D` 與 `X` 不會複製或刪除；`Home` 回到 World 視角。切回 World 相機後 `Shift` + `D`、`X` 照舊。
- 控制點在地面上沒有影子，左上角文字清楚可讀。
- 開啟 `Shadows` 等光影選項後，仍能點選與拖曳控制點。
