# 列車與軌道外觀

## 有什麼

- 方塊風經典雲霄飛車：階梯狀流線車頭的前導車加五節車廂，每節沿軌道各自轉向；深紅車身、奶油色腰線、金邊、黑色座椅與鍍鉻壓桿；每節並排兩位方塊人乘客，動作依軌道變化；前導車有頭燈，最後一節有尾燈。
- 方塊風的鐵軌與枕木，枕木依弧長等距擺放；三種樣條（Linear、Cardinal、B-spline）。

## 怎麼到達

`Grand Tour` 或任一軌道；World 或 Chase 相機看得最清楚。

## 怎麼用 CLI 驅動

- 成功：`smoke -Only cameras-chase`；看列車細節可用 `screenshot -Name train-close -AppArgs '--camera','chase','--u','30'`。
- 夜晚的車燈：`screenshot -Name train-night -AppArgs '--camera','chase','--time','22'`。
- 枕木間距由 `TrackSpacingCheck` 測試；樣條沒有 CLI 參數，要在面板上切換。

## 容易騙過檢查的假象

- 直線段上各節車廂不會互相穿插，彎道才看得出來，所以要多換幾個 `--u`。
- 靜止的截圖看不出行駛中的晃動變形。

## 手動檢查

- World 相機下，列車是前導車加五節車廂，轉彎時各節各自轉向、不互相穿插；前導車是階梯狀車頭，有鍍鉻保險桿、發亮的頭燈與金色星徽。
- 每節兩位乘客並排，手與身體不穿過車壁或彼此；平路時雙手握在壓桿上、偶爾轉頭或揮手，爬坡時手握壓桿、往上看，下坡時多數人高舉雙手並後仰（少數人仍握壓桿），彎道時身體往外側傾，動作隨軌道平順變化，不會突然跳動。
- 行駛或靜止時，駕駛室與綠衣服乘客都不會晃動變形；夜晚車頭燈與尾燈會發亮。
- `Grand Tour` 用三種 spline 各跑一圈：軌道沒有銳角的急彎或髮夾彎（岩山往東北出海、火山口上方的轉彎都是平順的大弧線）。
